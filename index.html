Projetos em Ciência de Dados

Ensaio de Machine Learning

Para melhor compreender o comportamento prático de diferentes algoritmos de Machine Learning nas frentes de Classificação, Regressão e Agrupamento (Clusterização).

Em cenários reais de aplicação, modelos frequentemente falham por problemas de ajuste — como memorização excessiva dos dados de treino (overfitting) ou falta de capacidade de aprendizado (underfitting). Para contornar essa barreira, é necessário testar a performance dos modelos variando hiperparâmetros ao longo das etapas de Treino, Validação e Teste (Generalização).

As ferramentas utilizadas foram:

  • Python: Linguagem principal adotada para todo o fluxo de engenharia de dados e machine learning..
  • Algoritmos de classificação: KNN, Decision Tree, Random Forest e Logistic Regression.
  • Algoritmos de Regressão: Linear Regression, Decision Tree Regressor, Random Forest Regressor, Polinomial Regression e variantes regularizadas (Lasso, Ridge e Elastic Net).
  • Algoritmos de agrupamento: K-Means e Affinity Propagation.
  • Métricas de perfomance: R2,MSE, RMSE, MAE, MAPE, Accuracy, Precision, Recall, F1-Score e Silhouette Score.
